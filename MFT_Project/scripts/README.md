# Scripts

Python entry points for routine project workflows will be placed here. Planned
usage includes:

- Generating reproducible synthetic datasets that mimic market and text
  features.
- Running local smoke tests over the multi-modal dataset and model pipeline.
- Launching SHAP explainability jobs and exporting artefacts.

Each script will expose an intuitive CLI (argparse/Typer) so that end users can
run complex tasks with a single command.
